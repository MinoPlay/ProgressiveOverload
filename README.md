# Command Center prototype

This branch explores a dense, operational dashboard that treats the workout like a command queue.

## Concept
- Fast visual scanning for a single training session
- High-contrast panels for quick triage
- Designed around sequencing and next actions
- Feels like a control room rather than a generic fitness tracker

## Design goals
- Emphasize tasks and flow instead of nested navigation
- Make the workout feel active and command-driven
- Keep progress and metrics close to action moments
